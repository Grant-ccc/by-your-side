# DeepSeek 聊天：配置、验证与边界

[返回首页](Home.md)

## 当前状态

已改用 DeepSeek 官方 API 的 `deepseek-flash`（当前为 DeepSeek-V4.1-Flash），保留角色提示词、近期上下文、回复入库、用量记账、月度文字预算、重复请求去重与错误反馈。尚无真实密钥完成付费模型验证，因此不声称语气、延迟或实际费用已经验收。

本轮默认发消息后立即请求一次回复，不启用作息等待、主动留言、长期记忆、日程执行、图片或安卓通知。原型里的这些能力仍是示例。

## 本机配置

1. 在 [DeepSeek 开放平台](https://platform.deepseek.com/)创建 API Key，确认 API 账户余额；网页登录聊天与 API 计费是不同入口。
2. 在被 Git 忽略的 `.env.local` 填写以下变量，保留原有数据库配置：

```dotenv
DEEPSEEK_API_KEY=在本机填写真实密钥
AI_MODEL=deepseek-flash
AI_MONTHLY_LIMIT_CNY=20
```

3. 执行 `npm run db:migrate`，停止旧开发服务，再运行 `npm run dev`。
4. 页面刷新后显示“DeepSeek已配置”。这只表示本机有配置，实际可用性以真实调用结果为准。发送少量非敏感测试消息，检查回复、刷新后的历史和 DeepSeek 用量。

后端默认使用 `https://api.deepseek.com`，不需要业务空间 ID。可选 `AI_BASE_URL` 仅接受此官方地址或其 `/v1` 路径，拒绝其他域名。旧的百炼变量不再读取；不将百炼密钥转发给 DeepSeek。旧配置若包含 `AI_BASE_URL`，需改为 DeepSeek 官方地址或删除该项。

密钥不填聊天、不上传 GitHub、不放 `VITE_` 环境变量，也不打包进安卓。启用模型后，角色提示词和最近一段聊天会发给 DeepSeek；数据库与 GitHub 同步是不同的数据去向。服务仍只允许本机开发访问，尚无生产登录。

## 一条回复如何产生

用户消息先独立保存，随后客户端请求回复。服务端校验会话与来源消息归属，以数据库命名锁串行处理同一会话；预算记录锁在事务内预留额度，提交后才调用模型。成功后将回复、Token 用量与费用结算一次提交。回复用 `reply_to_message_id` 唯一约束去重。

历史上下文最多读取最近24条，再限制文本总量；旧消息仍在数据库，但不保证每次都进入模型。当前没有摘要或长期记忆，不能承诺永久记住所有对话。角色提示词在 `apps/server/src/character.ts`，是项目原创适配，并非官方台词库。

模型使用非思考模式、非流式单次返回，最多512输出 Token。页面只在真实请求进行时显示“正在输入”，不会伪装角色已读。刷新只读取记录与任务状态，不自动发起付费生成。

## 费用与失败

初期月度文字预算默认20元，可在本地调整至不超过50元；此处是工程默认值，不含图片、服务器或其他服务。月度按北京时间计算。

费用按2026-10-15核对的 DeepSeek Flash 高峰、缓存未命中价格保守估算：输入2元/百万 Token、输出8元/百万 Token。官方空闲时段价格减半，缓存命中输入另有优惠；当前预算账本统一按较高单价计算，不追踪假日或缓存优惠，可能提前达到本地预算。成功后按模型返回的 Token 用量缩减预留，得到的仍是费用上限估算，数据库历史字段 `actual_cost` 也不代表供应商实扣账单。实际费用以 DeepSeek 控制台为准。价格或模型变化需要重新核对成本策略，暂不开放任意模型名称。

- 已保存的回复再次请求时返回原记录，不重复调用模型。
- 明确拒绝的配置或限流错误释放预留；用户手动重试才启动新一次尝试。
- 连接中断、异常响应、回复不完整或用量无法确认时，不自动重试。费用暂按预留上限计入，`actual_cost` 保留为空，实际账单以 DeepSeek 为准。
- 进程在调用期间中断时，保留 `running` 与额度预留，阻止同一会话继续生成；需要开发者核对供应商账单和本地任务后修复，当前没有自动对账或恢复按钮。
- 预算不足时停止新增生成，消息仍可保存。该限制仅覆盖本应用经此后端发起的文字调用，不能约束其他应用使用同一个密钥。

## 检查方法

```sh
npm run check
npm test
npm run build
npm run db:migrate
npm run test:db
# 保持开发服务运行：
npm run test:web
npm run test:local-chat
```

接口和适配器测试使用模拟响应；真库测试使用独立合成身份和模拟模型，验证回复与账本事务、去重、重连读取、并发预算和失败处理。浏览器模拟测试覆盖输入中、回复显示、刷新不重发和手动重试。以上均不产生真实模型费用，不能代替真实模型验收。

后续真实验收需使用少量非敏感样例，检查日常分享、情绪回应、连续消息、长上下文与角色一致性，再记录实际成本。真实聊天与截图不入公开仓库。

官方参考：[对话接口](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)、[模型价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[开放平台](https://platform.deepseek.com/)。
