# 安卓局域网最小连接实验

[返回首页](Home.md) · [v0.1 范围与验收](Trial-Scope.md)

## 方案与当前边界

采用 Capacitor 8 + 已有 React 界面生成安卓自用试验包，目标 SDK 为 Android 16 / API 36。界面资源内置在安装包；模型调用与 MySQL 继续留在电脑。

电脑保留原本的回环开发 API，同时另行启动只绑定指定私有 IPv4 地址的 HTTPS API，默认端口17402。手机粘贴电脑生成的一段配置，其中包含地址、独立访问凭据和证书 SHA-256 指纹。模型密钥不进入配置、手机或安装包。

安卓原生连接插件逐次检查已配对证书、有效期与标准主机名验证，不接受所有证书，不关闭 TLS 校验，不跟随 HTTP 重定向。后端所有读写（包括健康检查）先检查独立凭据，同时保留 Host/Origin 限制。配置只接受私有 IPv4 的 HTTPS 地址，不支持公网或穿透。

设备凭据保存在应用私有偏好中，不回传给网页代码，并排除系统云备份和设备迁移；不宣称已实现硬件密钥库加密。证书、私钥和配对配置保存在电脑的忽略目录 `.local/lan/`。这不是多人登录体系，不能作为公开服务部署。

当前已建立安卓工程、设置页、原生传输插件与构建工作流。电脑端真实 HTTPS、证书指纹拒绝、错误/缺少凭据拒绝、MySQL 保存读取及去重已通过。**安卓构建、Java 单元检查及真机安装结果分别记录，不把电脑端检查当成真机通过。** 本页后续将更新实际构建结果。

## 电脑准备

保持原有 `.env.local` 数据库与 DeepSeek 配置；不要把真实值放入公开文档。

```sh
npm ci
npm run db:up
npm run db:migrate
npm run setup:lan
npm run dev:lan
```

若发现多个网络地址，按提示指定真正用于手机 Wi-Fi 的电脑地址：

```sh
npm run setup:lan -- --host 192.168.1.100
```

上述地址只是示例，不直接复制。不要选 Docker、虚拟网卡或 VPN 地址。自动发现与启动都不会修改 Windows 防火墙、网络类型或路由器。

生成的 `.local/lan/手机连接配置.txt` 含访问凭据，只在自用设备间传递，不发到聊天或 GitHub。重复设置会保留仍有效的同地址证书与凭据；更换地址、证书过期或显式 `--rotate` 会生成新配对，需重启电脑服务并在手机重新粘贴。证书初期有效30天。

## 手机安装与连接

1. 从项目 Android 构建工作流取得试验 APK，传到自己的手机，按系统提示允许该次来源安装；无需开启 USB 调试或关闭系统安全功能。
2. 手机与电脑接入可互通的同一 Wi-Fi。打开应用 → 设置 → 连接我的电脑。
3. 完整粘贴电脑生成的连接配置，点“保存并连接”。配置保存后输入框清空；证书不匹配、凭据错误或服务不可达会显示原因。
4. 先验证连接和读取，再发送一条简短消息；关闭重开核对记录。只有发送与生成才可能发生模型费用，读取和连接测试不调用模型。

试验包是 debug 签名，不是应用商店或长期正式发布包。不同构建运行可能使用不同 debug 签名，更新时可能需要卸载旧包并重新配对；聊天保存在电脑数据库，但尚未确认的手机输入须自行保留。正式升级签名与交付方式在试用版交付前另行落实。

## 网络不通如何排查

- 电脑的 `dev:lan` 终端必须保持运行；手机上的 `localhost` 指手机自己，不能填它来连接电脑。
- 先执行 `npm run test:lan`。这只验证电脑访问自身局域网接口，不证明手机可达。
- Windows 当前网络若为公共网络，不擅自改为专用或开放全部入站。使用自己信任、设备可互通的网络；需要放行时仅考虑当前地址、该 HTTPS 端口及本地子网的专用网络规则，不关闭防火墙。
- 校园网、访客 Wi-Fi 可能隔离设备。同名 Wi-Fi 不保证互通，可在可信的个人热点/家庭网络重新验证；不为绕过隔离部署公网穿透。
- 证书校验失败先核对手机时间与电脑当前连接配置，不通过“忽略证书错误”来修复。
- 配置变更和有待确认消息同时发生时的恢复体验仍属于 T05 后续整体验收；本轮不把异常恢复全部标为完成。

## 构建与验证

```sh
npm run check
npm test
npm run build
npm run test:lan
npm run android:sync
# 有 JDK 21、Android SDK 36 的环境中：
cd apps/web/android
# Windows 使用 gradlew.bat；Linux 使用 bash gradlew
```

GitHub Actions 的 `Android trial APK` 工作流执行前端构建、Capacitor 同步、Java 安全规则单元检查和 debug APK 构建，再提供保留14天的安装包制品。工作流不读取本机 `.env.local`、配对文件或模型密钥，包内不包含用户连接配置。

本机目前未安装 JDK/Android SDK，先使用构建工作流；不因缺少本机 SDK 就虚构本机 APK 编译或设备测试通过。
