# 产品与第一版范围

[返回首页](Home.md)

## 产品功能基线

- 角色背景与关系通过私有配置定义，具体个人设定不进入公开 Wiki。
- 微信式文字短消息，通常一两句一条，偶尔连发；不需要语音。
- 工作、用餐、休息和事件影响回复节奏。忙时连续收到的消息，回来一起回应。
- 明确需要陪伴时可通过自然语言或按钮进入陪伴模式，减少普通日程造成的等待；可退出。
- 角色在自然、带随机性的节点主动联系。未回复时仍可留言，但不催回复、不查岗；长期未回复后降低频率。
- 保留可查看的日常时间线。用户可调整角色的大致作息，手动提供课表、考试和待办。
- 支持自定义习惯与适度反馈，不把未打卡当成没完成。
- 普通偏好自动保存并提示；重要约定和关系变化确认；不确定推断待确认。可查看、修改、删除。
- 携带物品影响出行事件和见闻，纪念品与相册保存共同经历。
- 支持物件、风景、棉花娃娃等相册构图，个人形象配置与参考照片不公开。
- 图片无需逐次询问，每周最多两张，且受月预算限制。
- 通知隐藏名字和正文，只给通用新消息提示；允许延迟。
- 支持备份、换机恢复和导出。

## 视觉与人物

保留既有参考中的双人头像、波浪背景、日常记录/习惯打卡/备忘录分页与卡片结构。主色为偏红、减少紫调的暖酒红。最新反馈是相关图片需要更萌。

角色资料分为官方材料、归纳推断、私有配置与应用内事件。收集的剧情不会自动成为应用内共同记忆。人物语气通过样例校准，不用单一标签代替塑造。

## 第一版交付边界

六类体验均保留为目标，但可按里程碑分批实现。早期事件库从少量完整分支开始，优先验证连贯性。新增朋友角色以数据隔离和角色配置复用为方向，不在第一版制作角色市场。

暂不增加语音、视频、3D/Live2D、多人社交、真实购物和物流，也不把商城、货币与共感等级作为必需功能。

## 主要验收

| 情境 | 期望 |
| --- | --- |
| 忙时连发三条 | 返回后综合回应，不逐条重复触发生成 |
| 明确请求陪伴 | 两种入口有效，可退出并合理恢复日程 |
| 连续未回复 | 留言自然且不催促，记录可回看 |
| 确认一起看电影 | 澄清时间、避免冲突、确认一次后落入安排 |
| 修改/删除记忆 | 后续生成不继续采用被撤销事实 |
| 重新回复 | 替换旧版本，相关派生事实同步处理 |
| 换携带物品 | 事件条件、过程或结果有所不同 |
| 周额度两张已满 | 不再生成第三张，不假报图片成功 |
| 预算达到硬上限 | 停新付费任务，旧内容仍可读 |
| 导出与恢复 | 消息、有效记忆、安排和相册关联可恢复 |

人物语气由具体对话样例评审，不承诺永不跑偏或永不遗忘。通知送达条件由目标设备实测记录。
