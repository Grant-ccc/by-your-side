# v0.1 手机聊天试用版：范围与验收

[返回首页](Home.md)

日期：2026-10-15。连接方式已由项目所有者确认；以下功能边界是本轮整理的可审阅基线，后续调整需在本页记录。

## 一句话目标

在目标安卓手机安装应用，手机与电脑连接同一 Wi-Fi、电脑运行后端时，可以与指定角色进行自然的文字聊天，重开后找得到记录，回复不满意时能替换最新一条，数据和费用有基本保护。

一个具体用途：打开应用分享今天的事，连续聊几轮，关闭再打开仍能看到上下文；某条最新回复不合适时重新生成，网络出错时明确显示结果，不重复保存或悄悄再次付费。

本版是可日常试用的小版本，不等于原六大模块全部交付。原需求继续保留为完整产品目标。

## 使用条件与限制

- 单个使用者、单个角色、一个主要聊天会话；不做角色市场或朋友账号。
- 手机与电脑在可互通的同一 Wi-Fi；电脑需保持开机且后端、MySQL 运行，电脑还需能访问模型 API。暂不支持校园网隔离、跨网络穿透或外出访问。
- 手机安装包内置界面，连接电脑后端；手机不直接连接 MySQL，模型密钥只在后端本地配置。
- 本版主要验证前台聊天。关闭应用后不承诺主动联系或通知；重新打开读取服务器已保存的结果，不因重开自动重复调用。
- 不做离线聊天与离线发送队列；无连接时提示原因，不假报消息已送达。
- 保留暖酒红视觉方向和现有占位美术，本版不以重新绘制全部头像、物品或相册为完成条件。

同一 Wi-Fi 不代表现有网页已经能在手机使用。当前 API 仅绑定回环地址、使用固定开发身份并校验 Host/Origin；接入手机前必须补充受控的局域网访问、设备访问凭据及连接配置，不能直接把开发接口暴露到公网。传输与安卓网络配置在下一步技术方案中明确。

## 本版必须做

| 项目 | 明确边界 | 当前情况 | 验收条件 |
| --- | --- | --- | --- |
| 安卓安装与连接 | 一个自用安装包，首次配置电脑服务地址与访问凭据 | 未实现 | 目标真机安装、打开、连接成功；地址或凭据错误有说明，不接受无凭据请求 |
| 文字聊天 | 用户主动发送后立即生成；短消息、真实输入中状态 | 本机网页链路已通 | 真机前台连续聊天、切走再回来可继续；生成失败不伪装成人物回应 |
| 历史与上下文 | 用户和角色消息持久化；近期上下文，不承诺长期记忆 | 已有存储与近期上下文 | 重开应用、重启后端后记录仍在；上下文能接住本次聊天，重复请求不多写 |
| 最新回复重生成 | 仅允许没有后续用户消息的最新角色回复；不改旧轮次 | 未实现 | 成功后界面和后续模型上下文都使用新回复；失败保留原回复；防重复生成与并发冲突，费用仍记账 |
| 连接和失败提示 | 区分断网、电脑服务未运行、凭据错误、模型失败及结果待确认 | 网页已有部分错误处理 | 各类故障有可理解反馈；结果不确定时先核查已有结果，不自动重发付费请求 |
| 文字费用限制 | 后端单独控制文字模型预算，显示保守估算与预留 | 已实现，真机待验证 | 额度不足停止新增调用，旧记录可读；所有重生成也计入预算；不将估算称为实扣账单 |
| 基础数据保护 | 可读聊天导出；开发工具完成数据库备份与恢复，不做应用内导入向导 | 未实现 | 导出不含密钥或设备凭据；在独立空白测试库恢复并核对消息，不覆盖现用数据库；明确费用账本不可因恢复旧备份而无声回退 |
| 人物语气验收 | 以具体连续对话评阅，不追求无限修改提示词 | v4 仍在校准 | 完成下方固定场景评阅，项目所有者认可可以日常试用，未通过项有明确记录 |

本版只需聊天、连接/费用设置和导出入口。已有主页可保留，未实现模块隐藏或明确标为预览；无需为了旧原型的全部按钮扩大后端范围。

“最新回复重生成”是原本已有目标，保留为本版的纠正手段。新增的反馈标签系统、自动学习偏好和全局提示词自修改均不在本版。

## 本版暂不做

| 后续能力 | 本版采取的处理 |
| --- | --- |
| 作息、忙后批量回复、陪伴模式切换 | 先即时回复，不模拟开会等待或虚构日程 |
| 主动留言、锁屏通知、后台可靠送达 | 不实现；可做隔离的技术可行性记录，不作为本版交付功能 |
| 长期记忆、课表、待办、共同约定、习惯 | 不自动提取或执行；只能使用近期聊天上下文，不宣称已设提醒 |
| 出行、物品分支、礼物与纪念品 | 保留规划，预览不当真实事件来源 |
| 图片生成、相册、双人形象、纪念日系统 | 不接付费图片服务，不生成图片 |
| 云部署、外出访问、账号体系、多人共享 | 后续单独确定成本与身份隔离方案 |
| 完整备份包、图片恢复、云同步与换机向导 | 先限定为聊天导出与开发工具备份恢复 |
| 消息反馈标签、自动根据反馈改角色设定 | 暂不增加，语气问题仍用具体对话人工校准 |
| 语音、视频、3D/Live2D、商城 | 不纳入当前范围 |

这些是延后交付，不是删除完整产品需求。总体费用目标继续保留，但本版只能核算文字调用与本地运行条件，不宣称已验证未来云服务和图片的总月费。

## 验收清单

每项分别记录“未实现 / 已实现待验证 / 技术检查通过 / 待用户体验验收 / 通过 / 未通过”，附实际日期、环境和证据。没有记录不能凭口头“应该能用”标记通过。

| 编号 | 操作 | 通过条件 |
| --- | --- | --- |
| T01 | 首次安装、配置并连接 | 所有者按说明可独立完成一次；手机连接的是电脑地址，不把手机 localhost 当电脑 |
| T02 | 前台连续发送并接收 | 正常返回真实文字；多次点击、响应丢失后核查不会产生重复消息或额外生成 |
| T03 | 关闭重开、后端重启 | 既有记录与已完成的回复仍能读取；重开不自动付费重生成 |
| T04 | 重生成最新回复 | 新版本成功替换并用于下一轮；旧轮次禁止修改；生成失败原回复还在；并发操作不导致多次替换 |
| T05 | 断网、停服务、错误凭据、模型异常 | 分别显示原因，用户原文可保留，失败不标为已读或已回复；未知结果不盲目重试 |
| T06 | 调低测试预算并尝试生成 | 普通回复与重生成均受限；旧内容可读，估算与实际账单的区别明确 |
| T07 | 导出并恢复备份 | 在独立测试库核对消息与关联；不包含密钥、访问凭据；恢复步骤不会无声重置本月费用控制 |
| T08 | 独立启动和恢复版本 | 所有者按说明启动、停止一次，并在临时副本演练恢复代码版本；代码回退与数据库备份分开说明 |
| T09 | 四组人物对话，每组三轮 | 日常分享、低落且不想听建议、轻微打趣、主动换话题；记录逐条评价，由所有者确认可接受的基线 |

T09 评阅重点：接得住前文，不机械追问、不说教、不追账，不把无来源事件或未实现工具说成已发生/已执行。若评阅中出现这些问题，记为未通过并说明修正，不用“个别样例不错”替代验收；这不是对未来所有模型回复零偏差的保证。

## 按流程如何往下走

1. 当前先收缩范围：本页作为审阅入口，完整目标与小版本分开。
2. 确定局域网安卓方案：安装包、服务地址、设备凭据、传输、电脑启动与费用边界，先做一次最小连接实验。
3. 补齐主要流程：连接 → 聊天 → 错误恢复 → 重生成 → 导出/备份；明确对应接口和数据版本规则。
4. 分块开发：每块绑定 T01—T09 中的具体条目，说明实现与验证状态。
5. 版本验收：技术检查与用户体验分别记录；所有必需项通过、严重问题解决后，交付试用包和说明。

进入下一版本前不自动追加功能。新需求先说明取代哪项、延后哪项或是否另立下一版本；模型措辞校准也不应长期取代安卓与数据保护的开发进度。

## 还没完成的决定

- 局域网访问与设备凭据的具体实现、安卓连接配置及传输方式：下一步方案阶段确定。
- 最新回复替换的版本和并发规则、备份恢复时的费用账本处理：开发前明确。
- 整体工期：尚未承诺；先完成最小安卓连接实验，再评估剩余工作。

这些待定项不影响本轮讨论功能范围，但未解决前不能声称手机版已可交付。
