# 在你身边：可点击原型

本阶段用于确认页面布局和操作流程，不是安卓安装包。暖酒红配色已按用户反馈调整。

## 打开方式

- 预览服务运行时，可在本电脑打开 http://127.0.0.1:13025 。这个地址只供本电脑访问，不是手机外网地址。
- 也可以双击本目录的《在你身边-原型.html》，无需安装依赖或启动服务。
- 独立 HTML 与网页预览各自使用浏览器的本地存储；切换打开方式时如需保留数据，请先导出再恢复。

## 建议体验顺序

1. 日常主页：切换日常记录、习惯打卡、备忘录，记录心情。
2. 聊天：发送文字，观察示例输入状态。忙碌演示中连续留言，再点击“忙完回来”；可进入和退出陪伴模式。
3. 打卡：记录运动/喝水等习惯，或添加自己的习惯；添加课程、考试、待办。
4. 物品：选择并确认携带物品，点击“演示一次出行见闻”，比较不同物品的事件。
5. 回忆：查看构图示意，添加新示意图片，体验每周两张的限制。
6. 设置：修改称呼、日期、作息；进入记忆管理进行修改、删除和约定确认。
7. 导出备份，再恢复该文件，查看数据是否保留。

桌面左侧有状态演示按钮；手机窄屏可从设置里的“原型演示”进入。空相册演示只显示空状态，不删除已有照片。

## 已实现的原型行为

页面导航、浏览器本地保存、示例聊天与消息批次等待、陪伴开关、最新回复替换、习惯记录、新增安排、确认约定、记忆修改和删除、物品条件事件、相册示意、预算暂停示意、JSON 导出与恢复。

备份包含示意图片 SVG 数据以及聊天、记忆、安排等状态，不含任何 API 密钥。恢复会替换当前示例数据，操作前会确认。

## 本阶段的边界

- 无 AI、服务器数据同步、真实费用、真实系统通知或后台定时日程；状态演示不是已完成的安卓功能。
- 聊天使用少量固定示例，不代表角色模型效果；任意输入不受示例覆盖时会明确提示。
- 大致作息只保存偏好，正式日程生成后续接入。
- 照片只表达构图，人物是临时示意。图片周额度是模拟值，不会自动随现实日期重置。
- 重置示例可以恢复初始状态；不要将原型当作唯一的私人日记保存工具。
